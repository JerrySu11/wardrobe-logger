How to make a token (once)
1. Open Fine-grained tokens → Generate new.
2. Resource owner: your account. Repository access: Only select repositories → personal_wardrobe.
3. Permissions → Repository → Contents: Read and write. Nothing else.
4. Generate, copy the github_pat_... string, paste it above. It's stored only on this device and can be revoked anytime.
